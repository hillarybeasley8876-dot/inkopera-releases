# 墨戏 INK OPERA — Releases

雪夜悬崖边的废弃古戏台，素面「墨客」与戏魂「霸王」一对一拼刀——水墨画风的魂类 Boss 战 Demo。

本仓库只放发布二进制：Windows 试玩包与实机演示母版。源码不在此公开。

## 下载

见 [Releases](../../releases)。

## 运行要求

Windows 10 / 11 64 位，需支持 Vulkan 的独立显卡（建议 RTX 3060 及以上）。首次启动会编译着色器，约需十几秒。

## 操作

| 动作 | 键鼠 |
|---|---|
| 移动 | W A S D |
| 轻刀 | 鼠标左键 |
| 重刀 | F |
| 格挡 / 弹刀 | 鼠标右键 |
| 闪避 | Shift |
| 跳跃 / 踏顶 | 空格 |
| 锁定 | Q / 鼠标中键 |
| 绝技 | E |
| 喝酒 | R |
| 收刀 | C |
| 暂停 | Esc |

本作是魂类硬核向——普通刀四刀即死，重刀三刀，危技两刀。别贪刀，退开的那几步才是活路。
